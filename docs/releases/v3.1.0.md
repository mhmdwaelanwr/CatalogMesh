# AI Product Photo Sorter v3.1.0

The first stable desktop release of AI Product Photo Sorter turns chronological product-shoot photos into an organized, reviewable catalog while preserving the original files.

## Highlights

- Cross-platform desktop GUI and CLI with shared processing and resumable SQLite state.
- Gemini, OpenAI, and Anthropic provider fallback with one to four keys per provider.
- Automatic quota and rate-limit key rotation across up to 12 configured keys.
- Live model discovery with shared-model validation across each provider key pool.
- Arabic, English, and Chinese interface support with persistent light and dark themes.
- Completed, pending, and failed views, live activity, ETA, graceful stop, and resume.
- Confidence review folders, classification/status/failure reports, usage tracking, and run history.
- Smart Photo Stack branding across the application, README, Windows icon, macOS icon, and Linux package integration.
- Native macOS application bundles for both Apple Silicon (`arm64`) and Intel (`x86_64`).

## Safety and privacy

- Source photos are never deleted, moved, renamed, or overwritten.
- API keys are masked in the GUI and may be stored in the operating-system keyring.
- Photos are sent only to the provider selected by the user.
- AI grouping is probabilistic; low-confidence output should be reviewed before catalog use.

## Known distribution limitations

The v3.1.0 binaries are not code-signed or Apple-notarized yet. Windows SmartScreen and macOS Gatekeeper may therefore display a warning on first launch. See `KNOWN_LIMITATIONS.md` and `PRODUCTION_CHECKLIST.md` for the current verification scope.

## PyPI

The repository includes an OIDC Trusted Publishing job. It remains disabled until the maintainer configures the PyPI Trusted Publisher and sets the GitHub Actions variable `PYPI_PUBLISH_ENABLED=true`.
