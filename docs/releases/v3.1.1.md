# Product Sorter Pro v3.1.1

`v3.1.1` is a maintenance and architecture release that keeps the v3.1 user-facing behavior intact while making the repository and Python package substantially easier to maintain and extend.

## Highlights

- Canonical runtime moved into `src/ai_product_photo_sorter/`.
- Existing source commands and top-level imports remain supported through thin compatibility shims.
- CLI, GUI, and setup wizard now have package-native entry points.
- Runtime path handling is centralized for source checkouts, installed wheels, and PyInstaller bundles.
- Tests, smoke tools, examples, and packaging files are organized into dedicated directories.
- PyInstaller and GitHub Actions are updated for the new package layout on Windows x64, Linux x64, macOS Apple Silicon, and macOS Intel.
- Frozen desktop builds can run the CLI worker through the same executable instead of depending on a loose Python source file.
- Added regression coverage for package boundaries, compatibility imports, release metadata, and legacy configuration location.

## Compatibility

This is intentionally a patch release. Existing v3.1 workflows remain supported, including:

- `python product_sorter.py`
- `python product_sorter_gui.py`
- `python set_data.py`
- `product-sorter`
- `product-sorter-gui`
- `product-sorter-setup`
- existing `.env` configuration and resumable output folders

No migration of user data or progress databases is required.

## Release assets

GitHub Actions builds and verifies:

- Windows x64 executable and ZIP
- Linux x64 standalone archive and Debian package
- macOS Apple Silicon app bundle
- macOS Intel app bundle
- Python wheel and source distribution
- SHA-256 checksum manifest

The Python package is published to PyPI through GitHub OIDC Trusted Publishing.

## Signing note

Desktop binaries are not yet code-signed or Apple-notarized, so Windows SmartScreen or macOS Gatekeeper may show a first-launch warning. Review `KNOWN_LIMITATIONS.md` before production deployment.
