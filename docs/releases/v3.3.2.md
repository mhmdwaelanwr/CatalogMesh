# CatalogMesh v3.3.2

CatalogMesh v3.3.2 completes the public package-name migration from the historical `ai-product-photo-sorter` distribution to **`catalogmesh`**.

## Highlights

- Makes `catalogmesh` the primary PyPI project and install name.
- Keeps the Python import namespace `ai_product_photo_sorter` unchanged in v3.x so existing imports do not break.
- Keeps legacy `product-sorter-*` commands and `PRODUCT_SORTER_*` persisted settings as compatibility aliases.
- Updates the public project links to `mhmdwaelanwr/CatalogMesh`.
- Updates Windows and PyPI documentation to use `pip install catalogmesh` and `catalogmesh-gui`.
- Keeps the existing tested Windows, Linux and macOS desktop artifacts and the same connector/publication safety boundaries.

## Install from PyPI

```bash
python -m pip install --upgrade catalogmesh
```

Desktop GUI:

```bash
catalogmesh-gui
```

Main CLI:

```bash
catalogmesh --help
```

## Compatibility

Earlier v3.x releases were published as `ai-product-photo-sorter`. That historical PyPI project remains part of the release history. New installations should use `catalogmesh`.

The internal import namespace remains:

```python
import ai_product_photo_sorter
```

This release does not change SKU confirmation, connector approval/reservation, Shopify publication, MCP mutation boundaries, or rclone automatic-copy safety behavior.
