# CatalogMesh v3.3.1

CatalogMesh v3.3.1 is a maintenance release that synchronizes the latest tested desktop GUI from `main` with the public Python package and release artifacts.

## Highlights

- Adds the professional icon presentation layer across all 12 desktop workspaces without changing the existing Tkinter/ttk layout or Notebook ownership.
- Adds provider visual identifiers for Gemini, OpenAI and Anthropic and focused action/status icon treatment while keeping text labels and runtime localization intact.
- Keeps EN/AR/ZH runtime behavior, light/dark themes and the existing connector safety boundaries unchanged.
- Refreshes the canonical packaged-Windows light/dark screenshots and generated README hero from the tested executable.
- Adds a dedicated Windows launch guide for both ready-to-run releases and PyPI installs.
- Publishes the latest `main` state as `ai-product-photo-sorter` 3.3.1 through PyPI Trusted Publishing.

## Windows

Recommended ready-to-run path:

1. Download `ProductSorterPro-windows-x64.zip` from this release.
2. Extract it.
3. Double-click `ProductSorterPro.exe`.

The executable filename is retained for v3.x compatibility; the application display brand is **CatalogMesh**.

PyPI path:

```powershell
py -m pip install --upgrade ai-product-photo-sorter
catalogmesh-gui
```

See `WINDOWS.md` in the repository for the full Windows guide and SmartScreen note.

## Release artifacts

The automated release pipeline builds and verifies:

- Windows x64 executable + ZIP
- Linux standalone tarball
- Linux Debian/Ubuntu package
- macOS Apple Silicon application ZIP
- macOS Intel application ZIP
- Python wheel and source distribution
- SHA-256 checksums

The packaged Windows executable is exercised by the automated GUI smoke workflow before release publication.

## Compatibility and safety

- PyPI package name remains `ai-product-photo-sorter`.
- Existing `product-sorter-*` commands and `PRODUCT_SORTER_*` settings remain supported through v3.x.
- `catalogmesh-*` commands remain the preferred branded aliases.
- Human-confirmed SKU/catalog identity remains required.
- No autonomous publication is introduced.
- Shopify, Akeneo and Odoo approval/reservation boundaries remain unchanged.
- MCP remains zero-publish and zero-remote-mutation.
- Automatic post-sort cloud transfer remains Copy-only.

This is a maintenance release; it does not introduce a new publication or connector execution model.
