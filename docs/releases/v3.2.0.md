# Product Sorter Pro v3.2.0

`v3.2.0` expands Product Sorter from a desktop photo-sorting workflow into a safer local-first catalog automation surface while preserving human review before SKU confirmation and publication.

## Highlights

- Added a persistent watched-folder daemon with crash-safe checkpoints and deterministic `added`, `changed`, and `removed` image events.
- Added `product-sorter-automation` with commands for shoot scanning, missing-asset audits, exact-stem local reconciliation, SKU candidate proposals, offline Shopify draft preparation, and watched folders.
- Added `product-sorter-watch` as a dedicated watched-folder console entry point.
- Added optional MCP support through `ai-product-photo-sorter[mcp]` and the `product-sorter-mcp` stdio server.
- Added MCP tools for `scan_shoot`, missing-SKU audits, candidate proposals, and human-confirmed Shopify draft preparation.
- Added deterministic Missing Asset Audit helpers for catalog rows and conservative local image reconciliation.
- Added the Agent Tool Registry foundation with explicit approval/mutation metadata and fail-closed execution boundaries.
- Hardened watched-folder checkpoints against concurrent temp-file collisions, invalid state paths, and corrupted snapshot entries.

## Safety boundaries

This release does **not** expose an MCP or automation `publish` tool.

- SKU candidate generation never auto-confirms a candidate.
- Shopify draft preparation remains fail-closed until every approved group has an explicit human-confirmed catalog match.
- Offline draft preparation performs zero network calls.
- Existing guarded Shopify publication remains separately confirmed, audited, idempotent, and rollback-aware.
- Source product photos are never moved, renamed, deleted, or overwritten by the watched-folder layer.

## New commands

```text
product-sorter-automation scan ./shoot
product-sorter-automation missing-assets ./catalog.xlsx
product-sorter-automation missing-local ./catalog.xlsx ./shoot
product-sorter-automation propose-matches ./approved_groups.csv ./catalog.xlsx --top-k 5
product-sorter-automation prepare-shopify-draft ./sku_matching/sku_match_manifest.json
product-sorter-automation watch ./shoot --state ./.product-sorter-watch.json --interval 5
product-sorter-watch ./shoot
```

Optional MCP installation:

```text
python -m pip install "ai-product-photo-sorter[mcp]"
product-sorter-mcp
```

## Catalog workflow

A compatible MCP host or automation system can orchestrate:

```text
scan shoot → show missing SKUs → propose matches → human review/confirmation → prepare Shopify draft
```

Human confirmation remains a mandatory boundary before the Shopify draft stage can succeed.
